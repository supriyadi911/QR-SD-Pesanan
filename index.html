Buku Panduan Penggunaan

Selamat datang di Sistem Kehadiran Digital Terpadu. Aplikasi ini dirancang untuk memudahkan manajemen kehadiran siswa berbasis QR Code dengan dukungan multi-jenjang (SD/SMP/SMA), sistem sesi (Pagi/Siang), dan tema warna yang dapat disesuaikan.

Aplikasi ini membagi hak akses menjadi dua peran utama: Admin TU (Hak akses penuh) dan Guru Kelas (Hak akses terbatas/sesuai wewenang).

BAB 1: PANDUAN UNTUK ADMIN TU

Sebagai Admin, Anda memiliki kontrol penuh terhadap seluruh pengaturan sistem, manajemen data (seluruh kelas), dan pembuatan akun untuk guru.

1.1. Login Pertama Kali
  • Buka aplikasi pada browser (disarankan Google Chrome).
  • Pada halaman utama, klik tombol Mulai Login.
  • Masukkan Username (silahkan hubungi Pengembang [Supriyadi : 082371962881]).
  • Pada kolom "Masuk Sebagai", pilih Admin TU.
  • Klik Masuk Ke Sistem.
1.2. Pengaturan Sekolah & Jam Masuk (Wajib Dilakukan di Awal)

Sebelum menginput data siswa, Anda wajib mengatur profil sekolah dan jam operasional:

  • Buka menu Pengaturan Sekolah di panel sebelah kiri.
  • Isi Nama Instansi, Tahun Pelajaran, dan Alamat Lengkap. Data ini akan otomatis tercetak di kop Surat Laporan dan Kartu QR Siswa.
  • Pilih Jenjang Aplikasi (SD/MI, SMP/MTs, atau SMA/SMK). Form pengaturan jam masuk di bawahnya akan menyesuaikan dengan jenjang yang dipilih.
  • Pilih Warna Tema untuk menyesuaikan tampilan aplikasi dengan identitas sekolah.
  • Di bagian Pengaturan Jam Masuk & Kelas:
    Tentukan Jam Masuk dan Toleransi Keterlambatan (dalam menit).
    Penting: Sistem menggunakan waktu ini untuk logika status otomatis. Jika siswa belum absen dan waktu masih berada dalam batas toleransi (Jam Masuk + Toleransi), statusnya adalah "Belum Presensi". Jika waktu melewati batas toleransi, status otomatis berubah menjadi "Alfa".
  • Catatan: Kolom ceklis kelas akan muncul secara otomatis setelah Anda menginput data siswa/guru. Centang kelas yang masuk di Sesi Pagi atau Sesi Siang.
  • Klik Simpan Pengaturan.
1.3. Manajemen Akun Guru

Untuk memberikan akses kepada wali kelas:

  • Buka menu Pengaturan Guru.
  • Klik tombol + Tambah Guru.
  • Isi Username, Password, pilih Jenjang, dan masukkan Kelas (misal: 1A).
  • Opsi Full Fitur:
    • Jika diaktifkan, guru tersebut dapat melakukan Scan QR, melihat Rekap, dan mengunduh Laporan.
    • Jika dinonaktifkan, guru hanya bisa melihat data siswanya saja (cocok untuk akun guru yang hanya bertugas memantau).
  • Klik Simpan.
1.4. Manajemen Data Siswa (Import Excel & Cetak QR)
  • Buka menu Data Siswa.
  • Cara Menambah Manual: Klik tombol + Siswa, isi form (NISN, Nama, Kelas, dll), lalu Simpan.
  • Cara Import Massal (Excel):
    • Klik tombol Template untuk mengunduh format standar.
    • Buka file Excel tersebut, isi data siswa. Pastikan format kolom NISN di Excel adalah "Teks" agar angka 0 di depan tidak hilang.
    • Simpan Excel, lalu kembali ke aplikasi dan klik tombol Import. Pilih file Excel tadi. Data akan tersinkronisasi.
  • Mencetak Kartu QR Massal: Klik tombol Cetak QR. Sistem akan otomatis menghasilkan file PDF berisi seluruh ID Card siswa dengan kode QR yang siap diprint dan dibagikan.
  • Hapus Massal: Centang kotak di samping nama siswa (atau centang "Pilih Semua" di atas), lalu klik tombol Hapus Terpilih.
1.5. Pemantauan & Modifikasi Kehadiran
  • Buka menu Rekap Absensi.
  • Filter data berdasarkan Tanggal, Kelas, atau Status (Anda dapat melihat siswa yang masih berstatus 'Belum Presensi' di sini).
  • Jika ada siswa yang lupa membawa kartu QR atau salah status, klik menu dropdown di kolom "Aksi" dan ubah statusnya (Hadir / Terlambat / Sakit / Izin / Alfa). Sistem akan otomatis memperbarui database.
  • Anda dapat menghapus data rekapan yang salah dengan mencentang baris tabel dan mengklik tombol Hapus Terpilih.
1.6. Cetak Laporan
  • Buka menu Laporan Absensi.
  • Pilih Rentang Waktu (Hari Ini, Tanggal Spesifik, Bulanan, Semester, atau Tahunan).
  • Pilih Target Analisis (Semua Siswa, Per Kelas, atau Individu Siswa).
  • Statistik laporan telah dipisah antara siswa yang Hadir, Terlambat, Sakit, Izin, dan Alfa.
  • Klik tombol PDF atau Excel untuk mengunduh laporan resmi yang siap diserahkan ke Kepala Sekolah.
1.7. Mode Layar Penuh (Fullscreen)

Untuk kenyamanan pemantauan atau jika Anda menggunakan aplikasi pada layar Kiosk (misal tablet di lobi sekolah), Anda dapat mengklik ikon panah (Expand) di sudut kanan atas layar (tepat di sebelah tombol Auto-Refresh) untuk membuat aplikasi tampil memenuhi seluruh layar.

BAB 2: PANDUAN UNTUK GURU KELAS

Guru Kelas menggunakan aplikasi ini untuk memantau absensi kelas yang menjadi tanggung jawabnya. Beberapa menu mungkin terkunci bergantung pada hak "Full Fitur" yang diberikan oleh Admin.

2.1. Cara Login
  • Buka aplikasi dari browser HP/Laptop.
  • Klik Mulai Login.
  • Masukkan Username dan Password yang telah diberikan oleh Admin TU.
  • Ubah "Masuk Sebagai" menjadi Guru Kelas.
  • Klik Masuk Ke Sistem.
2.2. Menggunakan Fitur Scanner (Oleh Guru/Petugas Piket)

(Hanya tersedia jika akun Anda memiliki hak "Full Fitur")

  • Buka menu Scan Kehadiran.
  • Izinkan akses Kamera di browser jika muncul notifikasi (Pilih Allow / Izinkan).
  • Klik tombol Mulai Scan.
  • Arahkan kamera ke QR Code pada ID Card Siswa.
  • Aplikasi akan berbunyi (Bip!) dan layar akan menampilkan status:
    • Hijau: Siswa Hadir tepat waktu.
    • Kuning: Siswa Terlambat (Melebihi jam masuk + toleransi yang diatur Admin).
    • Merah: QR Tidak Valid (Siswa tidak terdaftar di kelas tersebut) atau sudah absen.
  • Proses absen selesai dalam hitungan detik untuk setiap anak.
2.3. Cek Data dan Rekapan Kelas
  • Pada menu Dashboard, Guru dapat melihat ringkasan statistik (Hadir, Terlambat, Sakit, Izin, Alfa) khusus untuk kelas yang dibinanya.
  • Di menu Data Siswa, Guru dapat mengedit informasi siswanya sendiri atau mencetak ulang QR Code siswa yang hilang (klik ikon QR warna biru di samping nama siswa, lalu klik cetak).
  • Di menu Rekap Absensi, Guru dapat menginput secara manual siswa yang izin/sakit hari itu melalui kolom Ubah Status (Hadir / Terlambat / Sakit / Izin / Alfa).

BAB 3: TROUBLESHOOTING (PEMECAHAN MASALAH)

  • Kamera Scanner Tidak Mau Terbuka:
    Pastikan perangkat Anda terhubung ke internet dengan protokol HTTPS:// (wajib untuk kebijakan keamanan browser). Pastikan juga Anda sudah memberikan izin kamera pada pengaturan browser HP Anda.
  • Titik Indikator Merah di Pojok Kanan Atas:
    Ini berarti aplikasi gagal terhubung dengan Database (Google Spreadsheet). Pastikan koneksi internet Anda stabil, dan URL Web App Google Script yang dimasukkan oleh Admin sudah benar.
  • Angka Nol (0) di NISN Hilang Saat Import:
    Sebelum copy-paste data ke template Excel, blok dulu kolom NISN di Excel Anda > Klik Kanan > Format Cells > Pilih jenis "Text". Baru setelah itu ketik atau paste NISN-nya agar angka 0 tidak dianggap sebagai rumus matematika oleh Excel.
  • Data Kurang Up-to-date:
    Nyalakan toggle (sakelar geser) "Auto Refresh" di pojok kanan atas (di bawah ikon Titik Database). Aplikasi akan diam-diam menyinkronkan data terbaru setiap 30 detik.
